Contexte :

D'abord remis au goût du jour à des fin de dépannage puis entièrement remanié, ce site est essentiellement destiné au B2B.
Il permet aux clients de passer commande et de consulter leurs documents présents chez Sanidel (sur le web et dans l'ERP) mais aussi d'exporter les documents et tout le catalogue en Excel.

Afin de maintenir les informations du site à jour (documents, images, articles, ...), une synchronisation en PHP a été mise en place avec la base de données de l'ERP.

Technologies :

  • PHP avec des librairies dont :
    • Fpdf
    • PhpExcel
    • PhpMailer
  • HTML 5
  • CSS 3
  • JavaScript + JQuery
  • Bootstrap
